# 気象情報 Discord Bot

気象庁などの一次情報源のデータを10分ごとに確認し、種類ごとのチャンネルへ**そのまま届ける**Botです。
解説・予想の練習・答え合わせの機能は持たず、図と観測値だけを投稿します。投稿には出典と時刻を付けます。

### 面ごとの切り出しについて
FXFE502・FXFE5782・AXFE578・AUPQ35・AUPQ78 は1枚に何面も並んだ図なので、境目(枠線と白い帯)を見つけて1面ずつ切り出します。
気象庁の図の並び(上段が上空の面、左が12時間・右が24時間予想)に合わせて送り先を決めています。
境目が見つからないときは、間違った切り出しを送らないように図の全体を投稿します。
もし面と送り先が入れ違っていたら、`sources.py` の `Panel(段, 列, ...)` の数字を入れ替えてください。

### ドップラーレーダーについて
気象庁はドップラー速度の画像そのものは一般に公開していません。公開されているドップラーレーダー由来のデータは
「竜巻発生確度ナウキャスト」なので、それを #ドップラーレーダー に投稿します。

## 過去データの選択画面(#過去データ)
種類ごとの embed にメニューがあり、図を選ぶ→日付と時刻(日本時間)を入れる→その時刻に近いデータが自分にだけ表示されます。
1. このBotがこれまでに投稿した図から探します(9月からの投稿も、名前を変えたチャンネルにそのまま残っています)
2. 衛星画像(IR・I4・WV・W2・W3・S1・S2)は、投稿が無い時刻でも、ひまわりの観測データから作ります(2015年7月以降)
3. 地上天気図は、投稿が無ければ気象庁の保存用天気図のページを案内します
4. 「記録した事例の一覧」ボタンで、台風・大雨のスレッドの一覧も出せます

気象庁は高層天気図・数値予報天気図・レーダーの過去の分を一般には公開していないので、
それらはこのBotが投稿した分(投稿を始めてから)だけが見られます。

## 以前の版から更新するとき
1. 更新して再起動したあと、`/setup_weather` を1回実行してください
   - 以前のチャンネルは**名前を変えて新しい構成に移します**(消さないので、9月からの投稿はそのまま残ります)
     例:#地上実況-asas→#地上天気図、#500-300hpa解析→#500hpa天気図、#ひまわり-赤外→#赤外-ir、#気象レーダー→#レーダーエコー合成図
   - 足りないチャンネルを作り、#過去データ に選択画面を置きます
2. アンサンブル予報は NOAA の GEFS をやめて、気象庁の図(FEFE19 など)にしました。`/ensemble_now` は無くなります
3. 使わなくなったチャンネル(#アメダス、#エマグラム-〜、#予報ノート など)は自動では消しません

## コマンド
| コマンド | 内容 |
|---|---|
| `/setup_weather` | チャンネルの作成・移行と、選択画面の設置(管理者) |
| `/past_panel` | #過去データ に選択画面をもう一度置く(管理者) |
| `/check_now` | 今すぐ新着を確認(管理者) |
| `/latest_images` | 衛星・レーダーの最新を今すぐ投稿(管理者) |
| `/windprofiler` | 地点を選んでウィンドプロファイラを表示 |
| `/mode` | 現在の投稿モードと理由 |
| `/case_start`・`/case_end` | 事例の記録を手動で開始・終了 |

## 投稿間隔の自動切り替え
| モード | 条件 | 画像の間隔 |
|---|---|---|
| 大雨監視 | 監視範囲のアメダスで1時間降水量30mm以上(弱まってから2時間は維持) | 10分 |
| 台風監視 | 気象庁が台風・熱帯低気圧を解析中 | 30分 |
| 通常 | 上記以外 | 60分 |

ひまわりの観測データから作る画像(I4・W2・W3・S1・S2)は取得量が多いので、最短でも30分ごと(`HSD_MIN_INTERVAL`)です。

## セットアップ
1. Discord Developer Portal でBotを作成し、トークンを取得
2. OAuth2 の URL Generator で `bot` と `applications.commands` を選び、次の権限を付けてサーバーに招待
   - チャンネルを見る / メッセージを送信 / 埋め込みリンク / ファイルを添付 / チャンネルの管理
   - 公開スレッドの作成 / スレッドでメッセージを送信 / メッセージ履歴を読む
3. `.env.example` を `.env` にコピーして、トークンとサーバーIDを記入
4. `pip install -r requirements.txt` → `python bot.py`
5. Discordで `/setup_weather` を実行

## Railwayで動かす場合
- Variables に `DISCORD_TOKEN` と `GUILD_ID` を設定
- **Volume を `/data` にマウントし、`DATA_DIR=/data` を設定**してください(投稿履歴・台風の経路の記録が消えないように)
- ひまわりの観測データは1回あたり約30〜40MBをダウンロードします。止めるときは `HSD_IMAGES=`(空)

## 注意
- 気象庁の防災情報サイトのデータは公式APIではないため、仕様が予告なく変わる可能性があります。
  取得に失敗した場合は `/check_now` の結果にエラー内容が表示されます。
- 沿岸波浪実況図は、気象庁のページが読み込んでいる画像を自動で探します。見つからないと表示されたら、
  ブラウザで気象庁の沿岸波浪実況図を開き、図を右クリック→「画像アドレスをコピー」したURLを `WAVE_IMAGE_URL` に設定してください。
- 出典:気象庁ホームページ、気象庁 ひまわり標準データ(NOAA Open Data Dissemination)、
  背景地図:地理院タイル、海岸線:Natural Earth、図の文字:BIZ UDゴシック(SIL Open Font License)
