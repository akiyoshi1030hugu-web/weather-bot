# 気象情報 Discord Bot

気象庁が公開している資料の新着を10分ごとに確認し、種類ごとのチャンネルへ自動投稿するBotです。
数値・図はすべて一次情報源(気象庁)から取得し、投稿には出典と更新時刻を表示します。

### 予報ノート
- 毎朝7時に #予報ノート にその日のスレッドを作り、チェック項目を投稿します。
- `/yoso` で高知の最高気温と降水の有無(1mm以上)を予想して提出します。締切は12時で、それまでは出し直せます。
- 翌日1時に、気象庁アメダスの10分値と照合して採点します(気温:誤差1℃以内10点・2℃以内7点・3℃以内4点、降水:的中5点)。
- `/score` で自分の成績(累計点・平均誤差・連続提出日数)を確認できます。
- 地点や時刻は `NOTE_STATION`・`NOTE_HOUR`・`NOTE_DEADLINE_HOUR` で変更できます。

### 数値予報の答え合わせ
- 9時・21時の解析図(AXFE578)が届くと、24時間前の初期値の予想図(FXFE502・FXFE5782)と並べて #予報の答え合わせ に投稿し、振り返り用のスレッドを作ります。
- 予想図は `DATA_DIR/nwp` に4日分だけ保存します(保存が始まった翌日から投稿されます)。

### 気象庁の予報との比較
- 予報ノートの作成時(7時)に、気象庁の予報(5時発表の最高気温と降水確率)を記録し、採点時に一緒に採点します。降水確率50%以上の時間帯があれば「降水あり」の予報とみなします。
- 毎月1日に、前月の検証(平均点・気温誤差・RMSE・降水的中率・見逃し・空振り・気象庁との勝敗)を投稿します。`/report` で今月の途中経過を確認できます。

### 事例アーカイブ
- 大雨監視・台風監視モードになると、#事例アーカイブ に事例のスレッドを作り、その間に投稿された図へのリンクを集めます(図は再送しないので通信量は増えません)。
- モードが通常に戻ると、期間と主な観測値をまとめ、振り返りの問いを投稿します。
- 前線の通過など、自分で記録したいときは `/case_start`、終了は `/case_end` を使います。

### 投稿間隔の自動切り替え
画像系の投稿間隔は、気象庁の観測・解析データをもとに自動で切り替わります。

| モード | 条件 | 間隔 |
|---|---|---|
| 大雨監視 | 監視範囲のアメダスで1時間降水量30mm以上(弱まってから2時間は維持) | 10分 |
| 台風監視 | 気象庁が台風・熱帯低気圧を解析中 | 30分 |
| 通常 | 上記以外 | 60分 |

切り替わると #気象レーダー(台風のときは #台風 にも)でお知らせします。`/mode` で現在のモードと理由を確認できます。
しきい値や範囲は環境変数で変更できます(`.env.example` を参照)。

`/amedas` で最新(10分ごと)のアメダス一覧表を、`/latest_images` で最新の画像をすぐに投稿できます。

## セットアップ
1. Discord Developer Portal でBotを作成し、トークンを取得
2. OAuth2 の URL Generator で `bot` と `applications.commands` を選び、次の権限を付けてサーバーに招待
   - チャンネルを見る / メッセージを送信 / 埋め込みリンク / ファイルを添付 / チャンネルの管理
   - 公開スレッドの作成 / スレッドでメッセージを送信(予報ノート用)
3. `.env.example` を `.env` にコピーして、トークンとサーバーIDを記入
4. `pip install -r requirements.txt` → `python bot.py`
5. Discordで `/setup_weather` を実行するとカテゴリーとチャンネルが作られます
6. `/check_now` で今すぐ確認できます

### 初回の動作
起動直後は「今の最新版」を記録するだけで、投稿は次の更新から始まります(再起動のたびに同じ図が重複投稿されるのを防ぐため)。
すぐに投稿を見たい場合は `POST_ON_FIRST_RUN=1` にして起動してください。

## Railwayで動かす場合
- GitHubにpushしてRailwayでデプロイ(Procfile で `python bot.py` が実行されます)
- Variables に `DISCORD_TOKEN` と `GUILD_ID` を設定
- **Volume を `/data` にマウントし、`DATA_DIR=/data` を設定**してください。
  これがないと再デプロイのたびに投稿履歴が消え、初回扱いに戻ります。

## 情報源を追加するには
`sources.py` の `PDF_SOURCES` に1項目追加するだけです。

## 注意
- 気象庁の防災情報サイトのデータは公式APIではないため、仕様が予告なく変わる可能性があります。
  取得に失敗した場合は `/check_now` の結果にエラー内容が表示されます。
- アクセスは10分ごと・1件ずつ間隔をあけて行っています。間隔を短くしすぎないでください。
- エマグラムは気象庁「過去の気象データ検索(高層)」の指定気圧面の値からMetPyで描画しています。描画は別プロセスで行い、終わるとメモリを解放します。
- 表の画像にはBIZ UDゴシック(SIL Open Font License)を使用しています。初回に自動でダウンロードし、`DATA_DIR/fonts` に保存します。
- 出典:気象庁ホームページ(https://www.jma.go.jp/)、背景地図:地理院タイル
- 画像の最新時刻は気象庁の時刻一覧(targetTimes)から取得しています。時刻を推測してURLを作ると気象庁に余計な負荷がかかるため、この方式を変えないでください。
