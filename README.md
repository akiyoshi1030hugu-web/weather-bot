# 気象情報 Discord Bot

気象庁が公開している資料の新着を10分ごとに確認し、種類ごとのチャンネルへ自動投稿するBotです。
数値・図はすべて一次情報源(気象庁)から取得し、投稿には出典と更新時刻を表示します。

## 現在対応している情報
| 情報 | 投稿先 | 備考 |
|---|---|---|
| 短期予報解説資料 | #短期予報解説資料 | 1〜2ページ目を画像化+PDF添付 |
| AUPQ35(500/300hPa) | #高層天気図 | 00UTC・12UTC |
| AUPQ78(850/700hPa) | #高層天気図 | 00UTC・12UTC |
| 地上実況天気図 ASAS | #地上実況-asas | 最新の実況図 |

## セットアップ
1. Discord Developer Portal でBotを作成し、トークンを取得
2. OAuth2 の URL Generator で `bot` と `applications.commands` を選び、次の権限を付けてサーバーに招待
   - チャンネルを見る / メッセージを送信 / 埋め込みリンク / ファイルを添付 / チャンネルの管理
3. `.env.example` を `.env` にコピーして、トークンとサーバーIDを記入
4. `pip install -r requirements.txt` → `python bot.py`
5. Discordで `/setup_weather` を実行するとカテゴリーとチャンネルが作られます
6. `/check_now` で今すぐ確認できます

### 初回の動作
起動直後は「今の最新版」を記録するだけで、投稿は次の更新から始まります(再起動のたびに同じ図が重複投稿されるのを防ぐため)。
すぐに投稿を見たい場合は `POST_ON_FIRST_RUN=1` にして起動してください。

## Railwayで動かす場合
- GitHubにpushしてRailwayでデプロイ(Procfile で `python bot.py` が実行されます)
- Variables に `DISCORD_TOKEN` と `GUILD_ID` を設定
- **Volume を `/data` にマウントし、`DATA_DIR=/data` を設定**してください。
  これがないと再デプロイのたびに投稿履歴が消え、初回扱いに戻ります。

## 情報源を追加するには
`sources.py` の `PDF_SOURCES` に1項目追加するだけです。

## 注意
- 気象庁の防災情報サイトのデータは公式APIではないため、仕様が予告なく変わる可能性があります。
  取得に失敗した場合は `/check_now` の結果にエラー内容が表示されます。
- アクセスは10分ごと・1件ずつ間隔をあけて行っています。間隔を短くしすぎないでください。
- 出典:気象庁ホームページ(https://www.jma.go.jp/)
